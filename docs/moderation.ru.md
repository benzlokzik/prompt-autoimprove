# Модерация

Необязательный сигнал спама/злоупотреблений оценивает входящие промпты и
передаёт результат в метрику безопасности. Он построен на
[`benzlokzik/spam-detector`][spam-detector] (вариант BERT/`transformers`,
дообученный на основе `cointegrated/rubert-tiny2`) и **по умолчанию отключён**.
Когда он выключен — или когда зависимость либо модель недоступны — пайплайн
выдаёт результат, побайтово совпадающий со сборкой без него.

## Область применения

- **Только русский язык.** Сигнал срабатывает лишь тогда, когда нормализованный
  промпт определён как русский (`detect_language(...) == "ru"`); англоязычные и
  прочие промпты не оцениваются.
- **Необязательная зависимость.** Модель и её стек `torch`/`transformers`
  находятся в группе зависимостей `moderation`; стандартная установка их не
  тянет.
- **Мягкая деградация.** Любая ошибка импорта, загрузки или инференса приводит к
  нейтральному результату: без флага и без штрафа.

## Включение

Установите группу и включите сигнал:

```bash
uv sync --group moderation
PAI_MODERATION_ENABLED=1 \
  uv run uvicorn prompt_autoimprove.api.http.app:app --port 8000
```

### Конфигурация

Все настройки используют префикс `PAI_MODERATION_`.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PAI_MODERATION_ENABLED` | `false` | Создать и подключить детектор спама. |
| `PAI_MODERATION_HF_MODEL` | `cointegrated/rubert-tiny2` | Идентификатор репозитория Hugging Face (или локальный путь) дообученного классификатора. |
| `PAI_MODERATION_THRESHOLD` | `0.8` | Значение P(спам), при котором (и выше) промпт отклоняется, если включена блокировка. |
| `PAI_MODERATION_WEIGHT` | `0.5` | Ограниченный коэффициент, на который оценка спама снижает метрику безопасности. |
| `PAI_MODERATION_BLOCK` | `false` | Отклонять промпты на пороге и выше, а не только штрафовать их. |

## Как используется оценка

Когда сигнал включён, нормализатор добавляет к флагам безопасности промпта
запись `spam:<score>`, где `<score>` — это `P(спам)` в диапазоне $[0, 1]$.
Этот флаг затем:

- **снижает метрику безопасности** $q_s$ на ограниченный коэффициент —
  $q_s \leftarrow q_s \cdot (1 - w_m \cdot p)$, где вес модерации
  $w_m =$ `PAI_MODERATION_WEIGHT`, а $p$ — оценка спама; и
- **при необходимости отклоняет запрос** до любого обращения к модели, когда
  `PAI_MODERATION_BLOCK=1` и $p \ge$ `PAI_MODERATION_THRESHOLD`; это
  возвращается как HTTP `422`.

## Где это видно

- **HTTP:** `POST /v1/improve` возвращает `safety_flags` промпта, включая запись
  `spam:<score>`, если она есть.
- **gRPC:** `Normalization.safety_flags` уже несёт эти флаги в потоковом
  сообщении `normalized`.
- **Фронтенд:** карточка кандидата показывает значок «Возможно спам» с процентом,
  когда сигнал срабатывает.

## Сборка образа с модерацией

Веса модели скачиваются из Hugging Face Hub во время сборки, поэтому образ
получается самодостаточным:

```bash
docker build \
  --build-arg INCLUDE_MODERATION=1 \
  --build-arg PAI_MODERATION_HF_MODEL=<ваша-hf-модель> \
  -t prompt-autoimprove:moderation .
```

Базовый образ — glibc Debian (`python:3.13-slim`), потому что у `torch` нет
wheels под musllinux; стандартная сборка остаётся компактной и без `torch`.

[spam-detector]: https://github.com/benzlokzik/spam-detector
